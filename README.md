# NEXORA

Premium multi-page technology website for **NEXORA** — a global consumer electronics brand experience.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Space Grotesk + Inter Tight

## Pages

- `/` — Cinematic homepage
- `/products` — Flagship product showcase
- `/products/[slug]` — Product detail (keynote-style)
- `/categories` / `/categories/[slug]` — Immersive categories
- `/innovations` — R&D and technology roadmap
- `/support` — Premium support experience
- `/about` — Company story

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
